Créer

Chaque pièce devient un SubTool sculptable. Unités réelles : bijoux en millimètres, figures en centimètres, bâtiments en mètres — un export OBJ garde ces dimensions.

1,0

Ajouter : glisser depuis une sphère crée une sphère enfant ; cliquer sur un lien en insère une. Déplacer, Échelle et Supprimer agissent sur la sphère touchée (Alt+clic supprime aussi). Glisser dans le vide tourne la vue.

Créer la peau

La peau est un maillage tout en quads, avec un polygroupe par partie du corps.

Courbes

Plume : clic = point anguleux, glisser = point lisse, toucher le premier point ferme la forme, Entrée ou double-clic termine. Éditer : glisser points et poignées, double-clic sur la courbe pour ajouter un point.

Forme → solide à plat
Courbe → cylindre extrudé
Créer le maillage

Le maillage créé est un SubTool sculptable. Pour souder un cylindre à un objet : Fusionner ↓ puis DynaMesh.

SubTools

Double-clic sur un nom pour le renommer. Alt+clic sur un objet pour le sélectionner.

Masque

Peindre : maintenir ⌘ (ou Ctrl). Avec ⌥ en plus : retirer le masque.

Polygroupes

⇧⌘+clic sur un groupe pour l’isoler, ⇧⌘⌥+clic pour le cacher, ⇧⌘+clic dans le vide pour tout réafficher.
